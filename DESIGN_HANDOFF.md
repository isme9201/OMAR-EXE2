# UI/UX Pro Max adaptation notes

The redesign uses the requested repository as a high-level reference for a deliberate design system, reusable component primitives, responsive behavior, visual hierarchy, and motion. It does not copy code from the repository.

The implementation contract is the **Editorial Atelier** direction in `ideas.md`: Arabic-first RTL composition, an editorial production-desk layout, strong hierarchy, accessible contrast, distinct interaction states, and no dead navigation routes.
